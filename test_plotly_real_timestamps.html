Test: Plotly con timestamp REALI (millisecondi Unix)

Scenario: Timestamp realistici (~1768220000000) come nel database reale
Obiettivo: Verificare se tickformat funziona con numeri grandi

Test Details

  • Base time: 2025-01-13 12:00:00
  • Timestamps in milliseconds (1736758800000+)
  • Session 1: 0-10 minutes (C10), 1-9 minutes (C11)
  • Gap: 20 minutes
  • Session 2: 30-40 minutes (C10), 31-39 minutes (C11)
  • Using tickformat: '%Y-%m-%d %H:%M:%S' (NO type: 'date')

Expected Result

  • ✅ Horizontal lines with visible gaps at session boundaries
  • ✅ X-axis shows formatted dates (NOT raw milliseconds)
  • ✅ Two traces visible (magenta + blue)

If This Fails

Then tickformat doesn't work without type='date', and we need a different solution
